## 已修复

### M1（中）系统程序按名字启动，可能运行同目录下的冒名文件

安装程序、卸载程序和主程序会启动 Windows 自带的 `powershell`、`tasklist`、`cmd`、`netstat`。以前只写程序名，Windows 会**先在当前运行的 exe 所在的文件夹里找**。安装程序通常在“下载”文件夹里运行，如果那里有一个别人放进去的 `powershell.exe`，就会被执行。

- 修改：新增 `winsetup.system_exe()`，这些程序一律用 `%SystemRoot%\System32` 下的完整路径启动（`ui/winsetup.py`、`ui/runtime_deps.py`、`ui/localmodels.py`）。
- 测试：`tests/test_v130_security.py` 检查路径确实在 Windows 目录下，并检查代码里不再有按名字启动的调用。

### M2（中）更新包没有校验值时也会安装

应用内更新会下载安装程序并运行。以前只在 GitHub 返回了校验值时才校验，没有校验值就直接安装；下载地址也没有检查。

- 修改（电脑和手机）：下载地址必须以 `https://github.com/Kerxs/XueXiTong-Plus/releases/download/` 开头；没有 SHA-256 校验值就不安装，提示去发布页手动下载；文件名里不允许带目录。
- 测试：别的域名、http、别人的仓库、带 `..` 的文件名、缺校验值、校验值不对，都被拒绝，前四种连请求都不发。

### L1（低）一行日志写错，出错时会再抛一个错误

`api/base.py` 里读取视频状态失败时的一行日志格式写错了（`"{}" % 值`），执行到就会抛 `TypeError`，把一次普通的失败变成一次异常。已改正，并把同处的响应内容截到 200 字。

### L2（低）卸载时删除目录的命令行

卸载后延迟删除安装目录是拼出来的一条 `cmd` 命令。目录名里的 `%` 会被 `cmd` 展开。安装目录是用户自己选的，不是攻击面，但名字里有 `%` 时可能删错地方。现在这种目录名直接不自动删除。

### L3（低）统计后台页面没有内容安全策略

后台页面加了 `Content-Security-Policy`（只允许页面自带的脚本和同源请求）、`X-Content-Type-Options`，原有的 `X-Frame-Options` 和 `Referrer-Policy` 保留。

### 阶段 1 已修的隐私问题（一并列出）

- 日志文件不再写整页学习通网页；登录用户名打码；旧日志保留 30 天、最多 30 个文件。
- 日志和推送消息里的账号、密码、TOKEN、API Key、推送地址替换为 `***`（原有机制，这次确认仍然生效）。

## 接受并说明

### L4（低）自建题库（TikuAdapter）不校验 HTTPS 证书

`api/answer.py` 对 TikuAdapter 的请求用了 `verify=False`。原因：这是用户自己搭的服务，常用自签名证书或 http；请求里只有题目文字，不带任何密钥。带 TOKEN 的题库请求都校验证书。保持现状。

| 项目 | 结果 |

| 安装内容解包 | 文件名不允许绝对路径、盘符、`..`；只接受普通文件；共用文件安装时再校验 SHA-256（有测试） |
| 卸载 | 只删除带安装标记文件的目录 |
| WebView2 引导程序 | 从微软固定地址下载，验证是微软的有效签名后才运行 |
| 遥测 | 名字白名单、崩溃脱敏、只走 https、关闭即删除；服务端再校验一遍，不存 IP（阶段 3，有测试） |

| Android 组件 | 只有主界面对外可见；服务和文件提供器不导出；广播接收器不导出；不允许系统备份 |

## 未解决的风险（需要你决定）

1. **安装程序和主程序没有代码签名。** Windows 会弹“未知发布者”，用户也无法确认文件确实出自你手。更新校验（M2）保证的是“和 GitHub 上的文件一致”，不是“出自作者”——如果 GitHub 账号被盗，校验照样通过。解决办法是购买代码签名证书，这一版没有做。
2. **Android 允许明文 http。** `usesCleartextTraffic="true"`。学习通的视频地址里有 http 的，自建题库也可能是 http，关掉会让这些不能用。明文连接里没有账号密码（登录走 https），但视频请求带着学习通的 cookie。
3. **应用图标用的是学习通官方图标加“PLUS”字样。** 这是商标和著作权上的风险，不是技术问题。权利人提出要求时需要更换图标（`THIRD_PARTY_NOTICES.md` 里已写明）。
4. **遥测默认开启。** 引导里有说明和开关，只收数字，`PRIVACY.md` 写明了范围。但默认开启本身在一些用户和一些地区的规定看来是敏感的；如果面向的用户对此在意，可以改回默认关闭（一处默认值）。
5. **统计后台的管理密码没有防暴力破解。** 只有一个密码，没有登录失败次数限制。请用足够长的随机密码（建议 32 位以上）；需要更强的保护可以在 Cloudflare 上给 `/api/*` 加访问策略（Cloudflare Access）。
