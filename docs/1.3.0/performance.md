# 1.3.0 性能测试报告

测量环境：开发用的这台 Windows 11 电脑（显示器刷新率约 240 Hz）。每次测量都用独立的数据目录、独立的注册表位置和独立的实例名，不碰已安装的版本。数字是这台机器上的实测值，别的机器会不同；有比较意义的是“改之前”和“改之后”。

## 结论

| 项目 | 改之前 | 改之后 |
|---|---:|---:|
| 空闲时 CPU（开着界面动画，没有任务在跑） | 2%–24% 一个核心，波动很大 | **约 2%–3%** |
| 空闲时 CPU（关闭界面动画） | 17%–23% | **0%–0.6%** |
| 空闲时每秒重绘 | 约 240 帧（跟着屏幕刷新率） | 开动画约 25–37 帧；关动画 0 帧 |
| 启动到界面加载完成（打包版，热启动） | 1.3–1.5 秒 | 没改（本来就没有瓶颈） |
| 启动到窗口显示（含启动动画） | 约 2.2 秒 | 没改 |
| 界面内存 | 约 265 MB | 没变 |
| 任务进程启动到登录 | 0.6 秒，内存峰值 65 MB | 没改 |

“改之前”的空闲 CPU 数字是在 1.3.0 开发过程中、修这两处之前量的；同样的代码在 1.2.9 里也有，所以 1.2.9 也是这个表现，但我没有单独对 1.2.9 的发行包测量。

## 找到并修掉的两个问题

### 1. 启动画面关掉以后还在不停重绘

启动画面里光标闪烁的动画写的是“一直运行”。启动画面关闭后窗口只是隐藏，动画还在跑，而隐藏的窗口没有屏幕刷新率来限制它，于是以每秒几百帧的速度空转。

- 表现：没有任务在跑，应用也占着一个核心的 17%–23%。**关闭“界面动画”的用户反而最严重**，因为别的动画都停了，只剩这一个在空转。
- 修改：动画只在启动画面可见时运行（`ui/qml/Splash.qml`）。
- 结果：关闭动画时空闲重绘从约 240 帧/秒降到 0，CPU 降到 0%–0.6%。

### 2. 几个很慢的“呼吸”动画让整个窗口按屏幕刷新率重绘

面板上有四个缓慢的呼吸效果：没有视频时的光晕、没有答题内容时的图标、运行中状态点、未填账号时“设置”上的提醒点。Qt 的动画只要在运行，整个窗口每次屏幕刷新都要重画一遍——在 240 Hz 的显示器上就是每秒 240 帧，而这些效果一两秒才变化一轮。其中“运行中”的状态点在整个任务期间（几小时）一直在跑。

- 修改：新增 `ui/qml/Pulse.qml`，用定时器每 80 毫秒走一步（每秒约 12 步）代替逐帧动画，四处都换成它。肉眼看效果一样。没有答题内容的图标以前在窗口最小化时也不停，现在和其他循环动画一样会停。
- 结果：空闲重绘从约 240 帧/秒降到 25–37 帧/秒，CPU 稳定在 2%–3%。

## 检查过、没有发现问题的地方

| 检查 | 方法 | 结果 |
|---|---|---|
| 启动各阶段耗时 | 在启动流程里加了计时，写进 `gui.log`（`startup:` 一行），打包版连测 3 次 | 进程启动到读配置 0.5 秒，创建主窗口 0.6–0.8 秒，共 1.3–1.5 秒。之后到窗口显示的约 0.8 秒是启动动画，属于设计 |
| 长时间运行内存 | 把相当于 12 小时、两个章节并行的任务输出（9 万条事件）灌给界面控制器 | 内存只多 3 MB；日志、任务、答题列表都有上限（432 / 30 / 6 行）；每条事件约 7 微秒 |
| 任务进程启动 | 打包版任务进程用模板账号运行 3 次 | 0.6–1.0 秒走到登录，内存峰值 65 MB |
| 验证码识别库的加载 | 检查导入位置 | 只在遇到验证码时才加载，不拖慢启动 |
| 答案缓存 | 阶段 1 已改 | 不再每查一题读一遍整个缓存文件 |
| 日志写入 | 阶段 1 已改 | 日志文件不再写整页网页；保留 30 天、最多 30 个文件 |

## 没有做的

- **界面内存 265 MB 没有降**。大头是 Qt Quick 和图形驱动本身，要降只能换界面技术或砍动画，不在这一版的范围内。
- **没有做真实课程的长时间实测**。上面的“12 小时”是把模拟的任务输出灌给界面，验证的是界面这一侧不泄漏；任务进程连着学习通跑几小时的内存和 CPU 没有量。
- **视频预览时的占用没有量**。预览用的是系统的 WebView2，占用主要取决于视频本身；网格模式同时解码多个视频会更高，所以提供了“关闭预览”。
- **手机端没有做性能测量**。

## 以后怎么复测

- 启动时间：看 `%APPDATA%\ChaoxingDesktop\gui.log` 里的 `startup:` 一行。
- 开启匿名统计后，启动时间、内存峰值、CPU 时间会作为数字上报，可以在统计后台按版本比较。
- 空闲重绘帧数：设置环境变量 `QT_LOGGING_RULES=qt.scenegraph.time.renderloop=true` 后启动，数 `gui.log` 里每秒的帧数。测试时同时设置 `CHAOXING_DESKTOP_SETTINGS_ORG`，避免读写真实用户的界面偏好。
