## 改进

- **AI 答题** 可以添加多个备用服务商并调整顺序：首选出错（连不上、超时、Key 无效、额度不足）时自动换下一个继续答题
- **AI 设置** 只需选服务商、填 API Key、选模型；填好 Key 自动列出能答题的模型，“测试一下”当场确认能不能用；不常用的选项收进“更多 AI 选项”

## 修复

- **运行面板** 窗口较矮或高分屏最大化时看不到运行日志（[#1](https://github.com/Kerxs/XueXiTong-Plus/issues/1)）
- **模型列表** 滚动时带着整个设置页一起滚，很难选中模型（[#1](https://github.com/Kerxs/XueXiTong-Plus/issues/1)）
