# 学习通PLUS

此桌面界面只提供学习通课程相关入口，不包含其他网课平台切换项。

## 安装

- **安装包（推荐）**：运行 `XueXiTong-Plus-Setup-<版本>.exe`，按向导选择安装位置和快捷方式。默认安装到当前用户（`%LOCALAPPDATA%\Programs\学习通PLUS`），不需要管理员权限。已安装时再次运行会升级，配置不受影响。
- **运行组件**：视频预览需要 Microsoft Edge WebView2 运行时（Windows 11 已自带）。安装程序会检查，缺少时可从微软官网下载并安装（只下载微软签名的官方安装程序）；失败不影响安装，之后可在 https://developer.microsoft.com/microsoft-edge/webview2/ 手动安装。
- **卸载**：在 Windows“设置 → 应用”里卸载 学习通PLUS，或运行安装目录里的 `学习通PLUS.exe --uninstall`。默认清除账号数据（账号密码和 cookies），取消勾选可保留；也可以删除整个配置目录（含设置和日志）。
- **免安装**：解压 `XueXiTong-Plus-Windows-<版本>.zip` 的全部内容，双击 `学习通PLUS.exe`。请保持同目录中的 `chaoxing-worker.exe` 和 `_internal` 文件夹完整。免安装版不会自动安装 WebView2 运行时。

## 使用

1. 启动时会先显示启动画面，程序在后台加载，加载完成后进入主界面。
2. 第一次启动会进入开始引导：欢迎 → 免责声明（需要在输入框里完整写一遍声明） → 填写账号密码、选择 cookies 登录，或“稍后配置” → 高级设置（答题来源、答题、通知推送，可“稍后配置”） → 开始使用。选择稍后配置时，运行面板顶部会一直提醒，直到在“设置 → 账号”里填好。之后可在“设置 → 关于”里重新查看引导。
3. 以后需要修改账号时，在“设置”页修改后点击“保存”。
4. 回到“运行面板”，在左侧“基本参数”里调整课程 ID、视频速度、并行章节数和未开放章节的处理方式，然后点击“开始运行”。开始时会自动保存参数；任务运行中参数会锁定。
5. 课程 ID 留空时，任务启动后会弹出课程选择窗口；不勾选任何课程则学习全部课程。

### 运行面板

- 顶部：开始运行 / 暂停（继续）/ 停止。暂停后正在进行的请求完成就停下，暂停的时间不计入视频观看时长和运行时长。
- 左栏：当前课程、当前章节、已完成任务数和运行时长；音视频任务进度；运行日志（可按信息/警告/错误筛选、复制、清空、收起）。
- 右栏：只读可视化面板。
  - 上方“视频”：静音播放当前学习通视频，播放位置和倍速跟任务进度一致，切换页面回来会接着播，任务看完显示“已看完”。没有播放控件或交互入口，使用 Windows WebView2 运行时。
  - 下方“章节检测”：题目一读到就显示，答案查找中标“查找中”，填好后标注 题库匹配 / AI匹配 / 随机作答，以及题库覆盖率和提交状态。面板只用于查看，不能点选或修改。

### 设置

账号、cookies 登录、重试间隔、章节学习次数、高级选项、外观（跟随系统 / 浅色 / 深色）、数据与隐私和关于信息。

高级选项（与开始引导里的“高级设置”相同）：

- 答题来源：答题方式（不查找 / 题库 / AI 大模型 / 题库 + AI）。本机模型可点“自动检测本机模型”一键填写；云端模型可在“常用服务”里选择服务商（DeepSeek、通义千问、Kimi、智谱 GLM 等），填写 API Key 后点“获取模型列表”选择模型。
- 答题：达到覆盖率时提交（默认开启）、最低覆盖率（默认 75%）、查题间隔、答错重做、判断题“正确 / 错误”的写法。
- 通知推送：Server酱、Qmsg酱、Bark、Telegram。

程序配置、cookies 和日志保存在 `%APPDATA%\ChaoxingDesktop`，可在“设置 → 关于”中点击“打开配置目录”直接访问。`config.ini` 里的账号、密码、TOKEN、API Key 和推送地址，以及 `cookies.txt`，都用 Windows DPAPI 加密保存，只有当前 Windows 用户在这台电脑上能解密；把配置复制到别的电脑或账户后需要重新填写。

需要使用 cookies 登录时，将 `cookies.txt` 放入该配置目录，并在设置中开启 cookies 登录。

## 从源码构建

在 Windows x64 上运行 PowerShell：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_windows.ps1
```

图标以[学习通官方 App Store 图标](https://apps.apple.com/cn/app/%E5%AD%A6%E4%B9%A0%E9%80%9A/id977946724)为底图，并在左上角添加 PLUS 标识。发行包附带 ICO、PNG 和官方原图。

脚本会在 `.build` 中准备便携 Python 和依赖，构建结果位于 `dist\学习通PLUS`，发行压缩包为 `dist\XueXiTong-Plus-Windows-<版本>.zip`。同时会生成安装包 `dist\XueXiTong-Plus-Setup-<版本>.exe`。
